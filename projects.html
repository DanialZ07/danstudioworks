Case Study Deep-Dive Live/Deployed

SRAI Qhalif Official Educational Portal

Client: SRAI Qhalif & Tadika Sinar Bestari Status: Live/Deployed Duration: 1 Month (Oct-Nov 2026) Stack: HTML5 / Vanilla JavaScript / Tailwind CSS / Cloudflare DNS / MYNIC

The Challenge & Institutional Need

Sekolah Rendah Agama Integrasi Qhalif & Tadika Sinar Bestari needed an authoritative, modern digital home to establish verified institutional trust, showcase school academic programs and infrastructure, and centralize student intake. The institution previously lacked a dedicated website, depending on dispersed social media channels that made parent outreach, curriculum discovery, and admission workflows inefficient.

Engineering & Codebase Architecture

1. Frontend Architecture

Architected a high-performance, fully responsive, multi-page educational web portal strictly using semantic HTML5, clean modular vanilla JavaScript (ES6+), and Tailwind CSS for utility-driven, lightning-fast rendering without unnecessary library overhead.

2. UI/UX Craftsmanship & Animations

Engineered custom visual identity featuring traditional Islamic geometric pattern overlays, modern frosted glassmorphism (backdrop-blur) navigation pills, an accessible floating mobile thumb dock/app-bar, and polished CSS preloader animations for smooth page load sequences.

3. Core Interactive Features

Integrated bespoke vanilla JavaScript interactive tab navigation, responsive Lightbox image galleries (curating Abu Bakar classrooms, Bilik Isolasi, surau, and campus facilities), and frictionless direct WhatsApp API click-to-chat alongside Google Forms routing for prospective student enrollment.

4. Infrastructure & Technical SEO

Managed official MYNIC .edu.my domain registration through Exabytes, configured Cloudflare DNS with universal SSL edge encryption and global caching, and authored comprehensive Open Graph social cards, canonical URLs, and XML sitemaps for precise Google Search Console indexing.

Verified Production Deliverables

  • 100% Deployed & Live: Operating continuously at https://srai.qhalif.edu.my/ with sub-second page performance across all modern browsers.
  • Institutional Verification: Verified academic identity under Malaysian MYNIC registry with Exabytes DNS management.
  • Facility Showcase: High-definition Lightbox galleries showcasing Abu Bakar classrooms, Bilik Isolasi, and prayer halls.
  • Direct Enrollment Inquiries: Immediate parent conversions through tailored WhatsApp API links and Google Forms integration.
